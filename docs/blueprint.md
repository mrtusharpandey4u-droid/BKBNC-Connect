# **App Name**: BKBNC Connect- Simplifying College Journey

## Core Features:

- Welcome Message: Display a welcome message when the user initiates the chat to greet the user and set expectations.
- Predefined Questions: Provide a set of predefined questions related to college admissions, financial aid, and student life in a dropdown format.
- Intelligent Answers: Employ a large language model tool to answer student questions based on provided institutional knowledge and general college information.

## Style Guidelines:

- Primary color: Navy Blue to convey trust and stability.
- Secondary color: Grey for clean backgrounds.
- Tertiary color: White for interactive elements and highlights.
- Clean and minimalist layout with ample whitespace.
- Use elegant, outline-style icons for predefined questions.
- Subtle transitions and animations to enhance user experience.
