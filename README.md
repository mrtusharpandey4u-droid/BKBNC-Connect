# BKBNC Connect: AI-Powered Student Assistant

**BKBNC Connect** is an intelligent, conversational AI platform designed to simplify the college journey for students at B. K. Birla Night College, Kalyan. It leverages state-of-the-art Generative AI to provide instant, accurate information regarding admissions, academics, and campus life.

## 🚀 Key Features
- **Intelligent Conversational AI**: Powered by Google Gemini Pro and Genkit to provide context-aware responses to student inquiries.
- **Dynamic FAQ System**: Predefined questions for quick access to essential information (Timings, Documents, Achievements).
- **Responsive UI/UX**: Built with a mobile-first approach using ShadCN UI and Tailwind CSS.
- **Real-time Interaction**: Features a smooth chat experience with "thinking" indicators and rich text formatting for links and documentation.

## 🛠️ Technology Stack
- **Frontend**: Next.js 15 (App Router), React 18, TypeScript, Tailwind CSS.
- **UI Components**: ShadCN UI (Radix UI), Lucide Icons, Framer Motion.
- **AI Backend**: Google Genkit, Gemini 1.5 Flash (LLM).
- **State Management**: React Hooks (useState, useEffect) & Server Actions.
